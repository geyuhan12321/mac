# 词典 · 桌面版（PySide6）

本地词典，核心是**联想**：点进一个词 → 读例句 → 例句里的词可以继续点 → 换到那个词 → 再读它的例句。

## 启动

| 方式 | 命令 |
|---|---|
| 双击 | `launch.bat`（pythonw 启动，不留黑框） |
| 命令行 | `python app.py` |
| 依赖 | 只需 `pip install PySide6-Essentials`（本机已装 6.12.0） |

窗口一开是空词库。想看版式与联想，点右上角 **示例**（7 条互链词条：跑 / 快 / 车 / 贵 / run / fast / bus）。

![词条页](preview/preview-run.png)

## 版式

黑白灰，没有色块。词目用衬线体 30pt，正文 11.5pt，标签一律 8pt 灰字＋字距，分隔靠 1px 细线（`#cfcfcf` / `#e6e6e6`），例句用左侧细竖线缩进，例句里的可点词只有下划线。

整个界面只用六个灰阶：`#111111` 正文/词目 · `#5f5f5f` 次级说明 · `#9a9a9a` 标签注释 · `#cfcfcf` 重分隔线 · `#e6e6e6` 轻分隔线 · `#f7f7f7` 悬停底色。

## 自动识别：导入一个字，句子里立刻能点

不用重开、不用手动刷新：

1. **批量加字**（`Ctrl+B`）——粘一串字，空格/逗号/换行都行，不用写释义。
2. 加完当场提示「其中 N 处已经在现有例句里变成可点链接（涉及 M 条词条）」。
3. **当前正在看的词条会自动重画**：刚才那句 `他跑得比我快。` 里，`他 / 我 / 比 / 快` 立刻全变成青色可点词，`跑` 保持加粗（当前词）。
4. 这个字自己的词条页，侧栏会列出「**出现在这些例句**」，点句子里的任意词继续走。

![加字后句子瞬间可点](preview/preview-instant.png)

**原理**：词库每次变动都会重建索引（词形表 + 中文最长匹配表 + 例句共现边），然后重渲染当前页。所以「识别」不是一次性扫描，而是**词库即索引**——加一个词，全库所有例句同时生效。

没写释义的字会带 `待补` 标签，词条页给出「补一条释义 →」，点进去就是编辑框。

## 联想怎么走

1. 例句里**带下划线的词** = 词库已有，点它换词条。
2. **灰色词** = 未收录的英文词，点一下弹「新建词条」，填一句释义就补上。
3. 停用词（the / to / of / a …）不加链接，免得一屏都是可点词。
4. 右侧「被这些词条的例句用到」= 反链；「例句里还没收录的词」= 待建词袋，一键进新建。
5. 右侧「出现在这些例句」= 倒查：这个字/词出现在哪些句子里。

## 识别规则：库里有就点得进去，没有就点不进去

例句渲染时逐字扫描，结果只有两种：

| 情况 | 表现 |
|---|---|
| 这个字/词在词库中 | 黑色下划线，点得进去 |
| 这个字不在词库中 | 普通文字，点不动 |
| 库里没有的**英文**实词 | 默认灰色可点（点了去建词条）；**严格模式**下同样点不动 |

- 严格模式开关：菜单 **视图 → 只让库里的字可点（严格模式）**
- 批量补字：菜单 **工具 → 从例句自动收词**，一键把例句里出现过的汉字全收进词库，收完立刻全部可点

![字 → 例句 倒查](preview/preview-word.png)

中文按**词库最长匹配**切（有「跑步」就整体切，没有退到单字）；英文按 `wordForms` 反查词形，`runs / ran / running` 都回到 `run`。

## 快捷键

| 键 | 作用 |
|---|---|
| `/` 或 `Ctrl+F` | 聚焦搜索 |
| `Ctrl+N` | 新建词条（带释义） |
| `Ctrl+E` | 编辑当前词条（改首条义项，其余保留） |
| `Ctrl+B` | 批量加字（只要词条名，不写释义） |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置正文字号 |
| `Esc` | 清空搜索 |
| 拖文件到窗口 | 直接导入 `.csv` / `.json` |

## 数据

- 文件：`data/words.json`（不存在会自动创建），UTF-8。
- 结构：与网页版 `collins-dict/data/words.json` **完全同构**，可以互相拷。
- 菜单「文件 → 打开数据文件夹」直达。
- 导入可选**合并（同名覆盖）/ 追加 / 覆盖全部**；导出 JSON 与 CSV（CSV 带 BOM，Excel 直接开）。

CSV 表头（中英文字段名都认）：

```
headword,lang,homograph,frequency,pinyin,ipa_uk,ipa_us,pos,definition,definition_zh,
example,example_zh,example_source,synonyms,collocations,labels,note,radical,strokes,traditional,tags
```

一行 = 一个义项，同名词条自动合并；多值用 `|` 分隔；`example` 与 `example_zh` 按位置对齐。


## 已知限制

- Qt 富文本不支持 flex / grid / 圆角 / 阴影，版式全用 table 搭，观感偏「工具软件」。
- 单字收录后，出现在合成词里也会亮（如收了「快」，`快餐` 里的「快」也可点）。这是最长匹配的取舍：词库有「快餐」时会优先整体切。
- 倒查是全局扫描（O(n)），词条上千后应改成倒排索引，几百条以内无感。
